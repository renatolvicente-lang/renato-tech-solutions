## 💻 Sobre o projeto

A **Renato Tech Solutions** é um projeto desenvolvido para apresentar serviços de assistência técnica especializada em computadores, oferecendo soluções para manutenção, formatação e otimização de equipamentos.

O site tem como objetivo facilitar o contato com clientes, apresentar os serviços oferecidos e fortalecer a presença digital da empresa.

## 🛠️ Serviços oferecidos

- 💿 Formatação e instalação de sistemas operacionais.
- 🧹 Limpeza e manutenção preventiva.
- ⚡ Otimização e melhoria de desempenho.
- 🔧 Diagnóstico e resolução de problemas.
- 🖥️ Suporte técnico para computadores.

## 🚀 Tecnologias utilizadas

- HTML5
- CSS3
- JavaScript
- PHP

## 🎯 Objetivos

- Desenvolver uma presença digital profissional.
- Facilitar o acesso aos serviços da empresa.
- Proporcionar uma experiência simples e intuitiva.
- Apresentar soluções tecnológicas com qualidade e confiança.

## 🎨 Identidade visual

O projeto utiliza uma identidade visual moderna e minimalista, com tons escuros, detalhes em roxo e elementos que remetem ao universo da tecnologia.
